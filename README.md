# Fast Teach

A responsive Thai tutor directory and booking demo built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser. No build tools or dependencies are required.

## Files

- `index.html` — tutor listings, filters, and booking forms
- `style.css` — responsive layout and visual styling
- `script.js` — search, filtering, sorting, favorites, and demo booking behavior

Tutor profiles and prices are sample data. Booking requests are not sent to a server.
